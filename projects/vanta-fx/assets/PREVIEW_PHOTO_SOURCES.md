# Real reference photos in HORIZON BOOST
These are **real photographs**, not generated art or computer-drawn illustrative scenes. Local CPU reference shader previews are computed from the photo pixels. They are NOT screenshots of live GPU filtering.

- assets/preview_photo_cc0.jpg — DSCOVR Falcon 9 launch photograph captured by SpaceX, public domain. Scikit-image sample data 0.25.2 skimage/data/rocket.jpg. https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.rocket
- assets/preview_portrait_publicdomain.png — NASA photo of astronaut Eileen Collins, public domain / no known copyright restrictions. Scikit-image sample data 0.25.2 skimage/data/astronaut.png. https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut

Each file is included with the offline app; no runtime tracking/network requests. User-selected local image still takes priority until reset.
