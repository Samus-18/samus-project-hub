# Thalvoryn Worldgen — V86 Stage 3 TEST

![Thalvoryn icon](../../docs/assets/thalvoryn-pack.png)

Experimental Minecraft Java and Horizon Rust world-generation packs based on JJThunder / ThunderFusion terrain and TREK structures. Contains Overworld, Nether and End worldgen changes, sky islands, caves and custom structures.

## Four tested variant names

Java Nether 1024, Java Nether 2032, Rust Nether 1024, Rust Nether 2032. See [PACKS_MANIFEST.json](PACKS_MANIFEST.json) for file names and SHA-256 values. All are V86 Stage 3 TEST; live Minecraft world generation was not verified in this public release batch.

## Important: redistribution rights review

The ZIPs contain structure files under namespaces including data/explorify/ and data/cristellib/, while their credits refer to other modified structures and all-rights-reserved works. The bundled TREK MIT license and supplied JJThunder/ThunderFusion CC0 license text do not automatically cover every third-party NBT or structure.

For that reason, complete ZIPs remain available only in the user's local files until the relevant licensing permissions are confirmed. The public repo publishes the icon, checksums, credit notices and version status, NOT copied third-party structure assets. See CREDITS_AND_ORIGINS.txt for original authors.
